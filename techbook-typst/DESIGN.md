# 设计说明

## 定位

**像书的技术书** Typst 基础库：屏读优先、书感版式。不追求印刷厂工艺（出血、装订、色标），追求「翻开像一本书、读着舒服」。

## 核心决策

| 决策 | 原因 |
| --- | --- |
| TOML 配置驱动 | 书目与版式可审查、可 diff，章节不写样式 |
| 唯一入口 `main.typ` | 只装配 include，正文在 `chapters/` |
| 正文衬线 + 标题黑体 | 中文书感；标题层级清晰 |
| 首行缩进 2em（可关） | 贴近纸书；`indent = "0em"` 可改回空行分段 |
| 对称版心 + 轻书眉 | 书眉=章名，页码居中；不做双面印刷书口 |
| 默认 JIS-B5，可选 A4/A5 | 纸书开本感；A4 便于大屏/打印草稿 |
| 章首页大留白 + 短线 | 翻到新一章的节奏 |
| 图注 `N-M` / 附录 `A-M` | 增删节不手改编号 |
| 代码块与正文同宽、轻量 | 长代码少折行；浅底上下细线，不抢正文 |
| 表格三线表 | 更像书，少格子噪音 |
| 调用块纯文字标签 | 无 emoji，信息密度优先 |
| `#preface` / `#appendix` | 前置后置不占章号 |
| state 注入令牌 | `let` 注入对子组件无效 |

## 分层

```text
config.toml → src/lib/tokens → src/theme / component / cover
                              ↑
                     main.typ + chapters
```

## 有意不做

- 印刷工艺（出血、装订、专色、色标）
- 与旧版 techdoc 的 API 兼容
- 教程风「目标—练习」强制结构（组件保留，非默认）
- 写作质量/文风门禁（writing-rules 负责）
- 索引/参考文献自动化（可后续扩展）
