# 对称目录是写作惰性

一份每章三节、每节三段、字数接近的目录，看起来很专业。作者常常也这么安慰自己：结构清晰。多数时候那不是清晰，是模板在替你决定章节边界。

## 现象：整齐得可疑

评审时见过一类目录：四章，每章四节，每节标题都是「概述 / 原理 / 实践 / 小结」。问作者为什么这样切，回答是「这样比较完整」。完整是模板的完整，不是问题的完整。问题有松有紧，目录却方方正正。

## 机制：内容密度本来就不均匀

真问题在有些地方拧成一股，在另一些地方只够写半页。强迫每节等长，作者就要注水或截断。注水的句子进入正文，截断的代价藏在「详见后文」里。

规范把「禁止对称填充」写成登记级规则：连续小节字数几乎相同要触发结构审查（E-009）。`spec_lint` 的 L-SYM-01 用字数雷同度做启发式，只提示不阻断，因为字数像不等于结构错。

## 证据：拆与不拆都有信号

| 信号 | 倾向 |
| --- | --- |
| 一节里有两个决策规则 | 该拆 |
| 标题要用「与」连接两个能力 | 该拆 |
| 一节中途要换个角度 | 该拆 |
| 拆出的节不足半页且无产出 | 不该拆 |
| 两节共用同一现象，拆开要重复铺垫 | 不该拆 |

（E-009）

判据不是美观，是：把标题当问题念，念出两个问句就拆。

## 代价：拒绝模板会失去「看起来很会写」

对称目录在截图里好看。不均匀的目录需要向协作者解释。这个代价值得付：读者按目录跳读时，均匀但无关的章节害处大于长短不齐的真结构。

另一个代价是时间。按内容切分要反复合并、拆开，比填模板慢。

两行以上勾「是」或后两行任意勾「是」，回去改大纲。

## 误区：把均匀误认为公平

给每章同等篇幅不叫公平。给紧要处更多字、给顺带处更少字才对得起读者时间。
