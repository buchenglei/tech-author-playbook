# 预判读不读得完

你手头多半只有一份目录、一段前言、一章样稿。要判断读者会不会读完，不能等全书写完。先问自己：如果只能看这两三样，你会查哪几处？

## 通读才能发现的问题，发现得太晚

编辑审选题看目录，作者互评看样章。全书通读只发生在交稿后。若判据必须读完全书才成立，预判就不存在，只剩事后统计。

六条判据只看目录与样章。勾「否」即为失效点。

| # | 判据 | 对准 | 不修的后果 |
| --- | --- | --- | --- |
| P1 | 前言有能被证据推翻的承诺 | 承诺 | 读者不知换到什么 |
| P2 | 每章能写出一句独立产出 | 承诺 | 章变资料堆 |
| P3 | 抽掉任一章，后文是否断链 | 结构 | 并列合集 |
| P4 | 每章三层职能落在哪一节 | 结构 | 平铺无转折 |
| P5 | 样章数字或强断言有出处 | 断言 | 不敢据以行动 |
| P6 | 样章推断句带「推断/未实测」 | 断言 | 猜测当事实 |

P1、P2 看承诺是否可核对。P3、P4 看结构是否扣得住。P5、P6 看句子是否可复检。

在本仓库用这六条勾过改造前的样书目录：P1 弱、P3 出现零依赖章、P5 多数句无出处。改造后 P1–P4 勾「是」，P5–P6 在单元冻结时逐条记台账。推断：对陌生书稿同样可勾（未实测）。

## 预判判据不能代替读者

六条全勾，仍可能没人读完。它只拦住可预判的失效，不产出卡点数据。读者任务测试只能由人做，这一点无法用判据兑换。

另一个代价是排序。先修哪条要按放大链起点，而不是按勾选顺序。

刚立项或只写了目录，先修 P1、P2，因为承诺是链甲起点。已写完一半，先修 P5、P6，停住断言虚那条链。目录已稳定，再动 P3、P4——结构改动成本低于返工句子。不修 P1 就改 P3，改完目录仍对不上承诺。不修 P5 就扩写，扩写的是未记账的句子。

「目录很清晰」「读感顺」进不了这张表。判据必须能写「是/否」，并指向具体文件位置。写不出位置的评价，不是判据。

预判给了下手顺序。从下一章开始做第一件可交付的事：写出承诺与边界，让 P1、P2 可勾。
