# 终审报告包说明（阶段 3）

全稿完成后，`workflow/06_终审/` 至少包含：

| 文件 | 谁写 | 模板 |
| --- | --- | --- |
| `01_读者终审.md` | 读者 Agent | `01_读者报告.md`，scope=full |
| `02_编辑终审.md` | 编辑 Agent | `02_编辑审校.md`，对象=全稿 |
| `00_人反馈汇总.md` | 人 | 自然语言 |
| `03_作者修订说明.md` | 作者 | 可参照 `03_作者改进方案.md` |

交付给人阅读的顺序建议：两份终审 → 人反馈 → 作者修订说明 → 交接包 `handoff/`。

注意：终审**不能**把 L2 写成已通过；交付状态仍按 TEAM-07。
