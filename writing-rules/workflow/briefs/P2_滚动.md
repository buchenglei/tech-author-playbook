# P2 章循环卡（阶段 2，每批 2–3 章）

1. **批内**：节级仍跑 S3 + G 门禁；写完切身份自审，每章一张 3 行卡（`05_章节滚动评估.md`，勿只写 `memory/`）：
   `章 | 卡点 | 是否违宪法/绑死 | 建议`；出现「阻断」→ 立即详评。
2. **交人**：装《章审包》`10_章审包.md`（正文 Markdown + 卡 + 断言/证据计数 + 偏离登记）→ 人签字（改了什么/裁了什么，**空签字无效**）。
3. **冻结**：签字覆盖的批次才能 `frozen`（脚本只置 `checking`/`candidate`）；改动走 revision。
4. **回写**：人的调整写入宪法（规则更新）；追认的偏离入宪法，收敛的记反例；更新术语与上批小结。
5. **并行**：人审第 N 批时可起草第 N+1 批，但未签批次不得 frozen、不得作为定稿依赖。
6. 每批后 `memory_maint.py books/<slug>`；分歧记 `00_阶段状态.json.blockers` 等人裁决。
