# 第 2 部分 读者

你无法观察读者。所以不能写"画像"，只能写**带来源标记的假设表**。画像读起来像了解，实际全是猜测。

## 2.1 读者假设表

每条假设三列：内容、来源、能支撑多强的断言。

| 标记         | 含义                     | 允许写法           |
| ---------- | ---------------------- | -------------- |
| `given`    | 用户或项目文档明确给出            | 可直陈            |
| `inferred` | 从可见证据推出（代码、报错、已有文档的写法） | 可直陈，注明依据       |
| `assumed`  | 你的默认假设，无外部证据           | 只能写条件句，不得支撑比较级 |

**AUD-01**（MUST｜脚本 S-AUD-01｜阻断）：每条假设必须有来源标记。无标记按 `assumed` 处理。


**AUD-02**（MUST｜自检｜阻断）：`assumed` 不得支撑比较级（更/不如/优于/适合）。判据：含这些词的句子，其依据假设必须是 `given` 或 `inferred`。

| 写法 | 判定 |
|---|---|
| "读者用过 `git rebase`，本节不解释变基原理" | 合格：`inferred`，前文已用过 |
| "新手最容易卡在这一步" | 不合格：`assumed` 支撑了"最容易" |
| "若你从没配过连接池，第 3 步会卡住" | 合格：条件句，承诺收窄 |

## 2.2 假设不足时收窄承诺

不是补写画像，是降承诺。

| `assumed` 占比 | 处理 |
|---|---|
| 少数 | 正文可直陈，交接包列为待验证 |
| 多数 | 全文改条件式（"若你的环境是……"），前言列假设清单 |
| 全部 | 不写这本书。改为"某场景下的实践记录"，明确单一场景 |

**AUD-03**（SHOULD｜自检｜登记）：假设表随交接包提交。人类验收者看这张表，比读正文更快发现定位错误。

## 2.3 起点能力清单

书籍不设自测题——读者在书店翻两页，没义务做题。但必须给出**可自查的能力清单**。

写法：每条一个动作，读者能立刻判断"我会不会"。

```text
开始读第一部分之前，你应该能：
- 用 strace 或 perf 看过一个进程的系统调用
- 解释 TCP 三次握手为什么不是两次
- 在没有 IDE 补全的情况下写一个 HTTP 服务
做不到第三条，先读附录 A 的环境准备。
```

**AUD-04**（MUST｜自检｜阻断）：起点清单每条必须是动作，不得是标签（"熟悉 Linux""有 Python 基础"）。标签无法自查。

**AUD-05**（SHOULD｜自检｜登记）：起点清单应指出"哪条不会时该先补什么"。只说要求不给路径，等于设了一道墙。

## 2.4 认知负荷：三条信号

不设概念数目上限。密度随主题族差异太大——概念书一章十个新术语正常，实战书一章四个就压垮人。硬数字会逼出两种作弊：塞附录，或拿"没超限"给自己免责。

**AUD-06**（MUST｜自检｜阻断）：出现任一信号即处理。

| 信号 | 判据 | 处理 |
|---|---|---|
| 一段两个未定义术语 | 同一段出现两个以上 `glossary.json` 未收录的术语 | 拆段，或先定义后用 |
| 读者需往回翻 | 本节用到的概念在后文才定义 | 前移定义，或本节改为先看现象 |
| 标题要连接两个能力 | 标题含"与""、"连接两个不同能力 | 拆节（§3.4） |

**AUD-07**（MUST｜脚本 S-GLOSS-01｜阻断）：术语首次出现即写入 `glossary.json`。四个字段：`term`、`def`（一句，≤40 字）、`first_seen`、`aliases_forbidden`。

## 2.5 学习设计：四级目标

书籍与资料汇编的差别，不在长度，在**有没有设计过的练习**。

| 级 | 目标 | 练习形态 | 判定 |
|---|---|---|---|
| **知道** | 能复述机制 | 判断、选择 | 唯一答案 |
| **会用** | 能完成操作 | 任务题，给输入与期望输出 | 可自动判定 |
| **会判** | 能诊断陌生故障 | 给现象，问原因与下一步 | 评分要点 |
| **会设计** | 能给方案并说明取舍 | 给约束，要求方案 + 放弃理由 | 评分要点 + 反例 |

**AUD-08**（SHOULD｜自检｜登记）：每章至少覆盖"会用"；"会判"每章至少一题；"会设计"每卷至少一题。

**AUD-09**（MUST｜自检｜阻断）：习题不得与正文例题同构。判据：解题步骤与例题重合过半即同构。换个数字不算新题。

## 2.6 读者位移必须是可观测动作

"理解 X"无法判定。写成动作。

| 不可观测 | 可观测 |
|---|---|
| 理解连接池耗尽的原因 | 给一段连接泄漏代码，指出泄漏点并说出修法 |
| 掌握索引优化 | 给慢查询与执行计划，选出该加的索引，并说明为什么不加另一条 |
| 理解一致性模型 | 给三种并发场景，判断每种该用哪个模型 |

**AUD-10**（MUST｜自检｜阻断）：`reader_after` 每条以动词开头，第三方能照着执行并判断是否完成。

## 2.7 门禁 G1

| 检查 | 方式 | 通过条件 |
|---|---|---|
| 假设表带来源标记 | 脚本 | 零缺失 |
| `assumed` 未支撑比较级 | 自检 | 抽 5 句零命中 |
| 起点清单全是动作 | 自检 | 逐条可自查 |
| `reader_after` 可观测 | 自检 | 每条能答"怎么算完成" |
