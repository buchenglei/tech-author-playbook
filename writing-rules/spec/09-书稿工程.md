# 第 8 部分 书稿工程

书不是更长的文档。它有单篇文档没有的问题：分卷、习题、索引、版次、多作者接口。**这些问题对你是放大版的**——一次会话写不完，你只能靠文件而不是记忆维持一致。

## 8.1 七个差异

| 差异 | 单篇文档 | 书籍 | 你的应对 |
|---|---|---|---|
| 跨度 | 一次会话 | 数十次会话 | `state.json` + 单元冻结 |
| 一致性 | 靠眼前可见 | 靠机制 | 术表 + 台账 |
| 结构 | 线性 | 分卷分层 | `outline.json` 分卷节点 |
| 读者 | 单一入口 | 多入口 | 三条路径 |
| 练习 | 无 | 四级习题 | 习题与正文分离存放 |
| 引用 | 少量 | 大量交叉 | 编号与引用由脚本生成 |
| 版本 | 一次性 | 多版次 | 版本锚 + 弃用标记 |

## 8.2 分卷与章群

| 规则 | 说明 | ID |
|---|---|---|
| 卷有独立主题 | 每卷能用一句说明"这一卷解决哪类问题" | BOOK-01 |
| 卷间可独立阅读 | 读第二卷不必先读第一卷（前置只在卷内声明） | BOOK-02 |
| 卷首有地图 | 一卷开头给该卷结构图与阅读顺序 | BOOK-03 |
| 章群有过渡 | 每 3–5 章为一个章群，群末有小结与钩子 | BOOK-04 |

**BOOK-01**（SHOULD｜自检｜登记）：每卷有一句主题说明。写不出，即该卷无主题，只是章的堆放。

**BOOK-02**（SHOULD｜脚本 S-BOOK-02｜登记）：卷间可独立阅读，跨卷依赖不超过 3 处。

**BOOK-03**（SHOULD｜自检｜登记）：卷首给该卷结构与阅读顺序。读者翻到第 300 页，需要知道自己在哪。

**BOOK-04**（SHOULD｜自检｜登记）：每 3–5 章为一个章群，群末有小结与钩子。

**BOOK-02 的检测**：把第二卷每个 `deps` 列出来，跨卷依赖超过 3 处，说明分卷切错了。

## 8.3 习题体系

四级，逐级减少确定性，逐级增加判读成分。

| 级 | 形式 | 判定 | 数量 |
|---|---|---|---|
| **L1 回忆** | 判断 / 选择 | 唯一答案 | 每节 1–2 |
| **L2 操作** | 完成任务，给期望输出 | 可自动判定 | 每节 1 |
| **L3 诊断** | 给故障现象，问根因与下一步 | 评分要点 | 每章 1–2 |
| **L4 设计** | 给约束，要求方案与取舍 | 评分要点 + 反例 | 每卷 1–2 |

**BOOK-05**（MUST｜自检｜阻断）：L2 及以上的习题必须给答案，答案给判定标准而不只给结果。只给结果的答案，读者不知道自己错在哪。

**BOOK-06**（SHOULD｜自检｜登记）：L3/L4 不宜有唯一标准答案。给"应提到的要点"清单，并给一个常见错误答案及为何错。

**BOOK-07**（MUST｜自检｜阻断）：习题不得与正文例题同构（AUD-09）。同构题只检验记忆，不检验迁移。

## 8.4 索引与编号

| 对象 | 编号格式 | 生成方式 |
|---|---|---|
| 章 | `第 N 章` | 大纲顺序 |
| 节 | `N.M` | 大纲顺序 |
| 图 | `图 N-M` | 脚本扫 caption |
| 表 | `表 N-M` | 同上 |
| 代码 | `清单 N-M` | 同上 |
| 习题 | `N.M-K` | 同上 |

**BOOK-08**（MUST｜脚本｜阻断）：编号与索引一律脚本生成，正文只写引用标记。手写编号在增删节后必然错乱，且错乱是静默的。

**索引条目来源**：`glossary.json` 的 `term` + 首现位置 + 全部出现位置，脚本生成"术语 → 节列表"。

## 8.5 配套仓库与版本对应

| 规则 | 要求 |
|---|---|
| 双态 | 仓库有 `main`（与书稿同步）与 `final`（出版快照） |
| 标签 | 每章冻结打 tag `ch03-frozen` |
| 对应表 | `VERSIONS.md` 记录"书稿版本 → 仓库 commit" |
| 可复现 | 每个代码块能定位到 `path:start-end` |

**BOOK-09**（SHOULD｜自检｜登记）：书稿行为若依赖特定版本，`VERSIONS.md` 应记录该版本。读者按书操作失败时，第一个要查的就是版本不对。

## 8.6 前言三件

前言不是客套，是**使用说明书**。

| 件 | 内容 | 缺了会怎样 |
|---|---|---|
| **读者假设** | 假设表摘要 + 起点能力清单 | 错位的读者读三章才放弃 |
| **未验证声明** | 哪些内容未实测、哪些是推断 | 读者把推断当事实 |
| **路径图** | 三条路径 + 各卷关系 | 读者不知道从哪进 |

**BOOK-10**（MUST｜自检｜阻断）：未验证声明必须具体到节，不得写"部分内容未经验证"。笼统的免责等于没有免责。

## 8.7 多 Agent 接口

由多个 Agent 分工时，接口是文件不是对话。

| 接口物 | 作用 | 谁维护 |
|---|---|---|
| `outline.json` | 结构契约 | 规划 Agent |
| `glossary.json` | 术语契约 | 全体，写入加锁 |
| `ledger.csv` | 事实契约 | 各写作者追加 |
| `style.kernel.md` | 文风基线（3–5 段例句） | 规划 Agent |
| `state.json` | 进度与阻塞 | 各写作者更新自己的单元 |

**BOOK-11**（MUST｜自检｜阻断）：`style.kernel.md` 必须存在且不超过一页。多 Agent 写作的风格漂移，靠规则约束不住，靠例句能约束住。

## 8.8 三道审校

| 审校 | 人类做 | 你做 |
|---|---|---|
| **技术审校** | 判断结论是否正确 | 提供每条断言的来源与复现命令 |
| **语言审校** | 判断读起来是否顺畅 | 跑 L0，输出问题清单 |
| **事实审校** | 抽查 | 全量台账核对 |

**BOOK-12**（MUST｜自检｜阻断）：技术审校包必须含"复现清单"：每条量化断言 → 命令 → 预期输出。审校者不读正文也能验证。

## 8.9 版次与修订

| 情形 | 处置 |
|---|---|
| 事实变更 | 改正文 + 更新台账 + 记 `revision` |
| 版本升级导致失效 | 该节标 `deprecated`，新增一节写新版本，不原地改 |
| 结构性调整 | 全书重跑 G5，索引重生成 |
| 读者反馈错误 | 先复现，再改，再回归（§7.7） |

**BOOK-13**（SHOULD｜自检｜登记）：不宜原地改写已发布的版本相关章节。保留旧版并标弃用，读者手上的旧书才对得上。
