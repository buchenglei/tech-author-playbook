# 附录 G 术语表

| 术语 | 定义 |
|---|---|
| **断言（claim）** | 可被证伪的事实陈述，带 E 级与编号 |
| **证据等级（E0–E3）** | 实测 / 一手 / 二手 / 推断，决定句式强度 |
| **单元（unit）** | 一节 = 一份 spec + 一次生成 + 一次校验 + 一次冻结 |
| **三层剥法** | 现象 → 机制 → 代价，层间留未解问题 |
| **位置（slot）** | 节内六个功能位：现象、机制、证据、代价、误区、收束 |
| **门禁（gate）** | 阶段之间必须通过的检查集合，G0–G7；G8 为工具层质量扩展 |
| **台账（ledger）** | 断言与来源的对应表，防虚构的第一道防线 |
| **冻结（frozen）** | 单元通过 DoD 后的状态，修改须走 revision |
| **回滚（rollback）** | 引入新失败的修改必须撤销，不得叠加补丁 |
| **交接包** | 交付人类验收的六文件集合，含未验证声明 |
| **文风基线** | `style.kernel.md` 中的 3–5 段例句，多 Agent 写作的风格锚 |
