# 第 1 部分 立项

一本书的失败，一半发生在动笔前。角度选错，结构再对也只是把一本多余的书做得很规整。

## 1.1 立项卡

文件：`kit/01_立项卡.json`。十一个字段，缺一不得进入结构设计。

| #  | 字段              | 要求                          | 缺了会怎样         |
| -- | --------------- | --------------------------- | ------------- |
| 1  | `title`         | 书名。含主题词，不含"深入理解""实战"这类无信息后缀 | 读者无法判断这是什么书   |
| 2  | `claim`         | 一句话承诺，必须可证伪                 | 写完发现没内容       |
| 3  | `increment`     | 增量类型（§1.2 六选一）              | 与已有书重复        |
| 4  | `reader_before` | 读者进来时的能力，可观测                | 定位错，全书白写      |
| 5  | `reader_after`  | 读者出去时的能力，动词开头，可观测           | 承诺无法验收        |
| 6  | `scope_in`      | 承诺覆盖的 5–12 个点               | 覆盖不全          |
| 7  | `scope_out`     | 明确不写的 3 条以上，每条给理由           | 范围失控，写到 60 万字 |
| 8  | `prerequisites` | 前置能力清单                      | 读者前三章放弃       |
| 9  | `sources`       | 至少 3 条 E1 来源，带版本与 locator   | 依赖二手信息        |
| 10 | `risk`          | 易过期内容 + 复审日期                | 两年后全书失效       |
| 11 | `kill_criteria` | 至少 2 条，可判定：什么情况下这本书不该写      | 明知无价值仍写完      |

**`claim` 的写法**：不是主题名，是一个断言。

| 不合格         | 合格                                                      |
| ----------- | ------------------------------------------------------- |
| "讲透 Kafka"  | "多数 Kafka 消费延迟问题源于消费组再平衡策略与处理耗时的错配，按处理耗时分层可定位八成延迟"      |
| "深入理解分布式事务" | "分布式事务的四种方案不是演进关系，而是按一致性要求与失败恢复代价形成的四象限，选错象限的代价远大于选错实现" |

**判据**：写完 `claim` 自问——什么证据能推翻它？答不出，说明它只是主题描述。

**TOP-01**（MUST｜脚本 G0 门禁｜阻断）：`claim` 必须是可证伪断言。判据：句中出现具体机制、条件或因果，且能构造一个反例。

**TOP-02**（MUST｜脚本 G0 门禁｜阻断）：`scope_out` 至少 3 条且每条有理由。没有"不写什么"就没有"写什么"。

**TOP-03**（MUST｜脚本 G0 门禁｜阻断）：`sources` 至少 3 条 E1，`url` 与 `locator` 均非空。空值不算填写。

## 1.2 六种增量

一本书必须比现有资料多点什么。六种增量，按可靠性排序：

| 类型      | 增量            | 例子                | 风险          |
| ------- | ------------- | ----------------- | ----------- |
| **判断**  | 给出取舍依据，别人只列选项 | "什么条件下选 A 不选 B"   | 需要真经验       |
| **联结**  | 把两个孤立领域接通     | "用排队论解释连接池参数"     | 易牵强         |
| **经验**  | 一手踩坑记录与误判过程   | "我们如何误判了三周"       | 需要真事        |
| **系统化** | 把碎片整理成体系      | "把散落的 40 个配置归成四类" | 会变成索引       |
| **时效**  | 覆盖新版变化        | "v5 之后旧写法全部失效"    | 半年即过期       |
| **表达**  | 同一内容讲到能懂      | "把源码讲成人话"         | 门槛最高，也最易被低估 |

**TOP-04**（MUST｜自检｜阻断）：`increment` 必须取自上表六项，并写一句"具体多在哪里"。写不出具体差异，说明这本书不需要存在。

**不可用的增量**："市面上缺少中文资料"——除非附检索记录：query、日期、命中数、实际读了几篇。缺记录视为未举证。

## 1.3 断言来源等级

这是全书最关键的一条机制。事实分四级，**等级决定句式**。

| 级      | 含义                 | 允许写法                | 不允许      |
| ------ | ------------------ | ------------------- | -------- |
| **E0** | 本机实测，有命令与输出        | 直陈，附环境              | 省略环境     |
| **E1** | 一手来源：官方文档、源码、规范、论文 | 直陈，附版本与 locator     | 写成"一般认为" |
| **E2** | 二手：博客、教程、他人转述      | "有资料提到……（来源），本文未复现" | 直陈       |
| **E3** | 你的推断，无外部依据         | "推断：……（未实测）"        | 直陈、省略标记  |

**CLAIM-01**（MUST｜自检｜阻断）：每个事实断言在台账有一行，标 E0–E3。无记录视为 E3。

**CLAIM-02**（MUST｜自检｜阻断）：E3 断言必须带"推断/推测/未实测"之一。缺标记即把推断伪装成事实。

**为什么用等级而不是"要有来源"**：因为"要有来源"可被绕过——把"会导致 X"改成"通常会 X"，检查就过了，错误留下了。等级绑句式，堵的是这条路。

## 1.4 "空白"断言的举证责任

写"很多人误解……""常见做法是……""很少有资料讲……"，等于声称一个关于世界的事实。

| 断言         | 需要的证据                         |
| ---------- | ----------------------------- |
| "很多人以为 X"  | 至少 3 处公开来源确实这么说，附链接           |
| "常见做法是 X"  | 至少 2 个真实项目的代码或配置              |
| "很少有资料讲 X" | 检索记录：query + 日期 + 命中数 + 读了前几条 |

**TOP-05**（MUST｜自检｜阻断）：三类空白断言无举证即删除，或改为第一人称经验（"我见过三次……"）。后者只需真实，不需统计。

## 1.5 五种否决信号

命中任一，停手或换角度。**不要靠"写写看"验证**。

| 信号        | 判据                 | 处置              |
| --------- | ------------------ | --------------- |
| **无一手来源** | E1 少于 3 条          | 换角度，或降级为实践记录    |
| **无法证伪**  | `claim` 构造不出反例     | 重写 claim        |
| **承诺过宽**  | `scope_in` 超过 12 点 | 拆成两本，或砍到 8 点    |
| **增量不具体** | 说不出与现有资料的差异        | 回到 §1.2 重选      |
| **时效过短**  | 核心内容 12 个月内会失效     | 改为"某版本的实践"并写明版本 |

## 1.6 门禁 G0

| 检查                  | 方式 | 通过条件             |
| ------------------- | -- | ---------------- |
| 十一字段齐全且非空           | 脚本 | 零缺失              |
| `claim` 可证伪         | 自检 | 能构造反例            |
| E1 来源 ≥3            | 脚本 | url 与 locator 非空 |
| `scope_out` ≥3 且有理由 | 脚本 | 零空               |
| `kill_criteria` ≥2  | 脚本 | 零空               |
| 无否决信号               | 自检 | 五项逐条排除           |

**门禁不过不得进入第 2 部分。** 立项错的成本是整本书，改立项的成本是一小时。
