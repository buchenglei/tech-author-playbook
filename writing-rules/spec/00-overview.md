# 技术书籍写作规范

| 项    | 内容                                                        |
| ---- | --------------------------------------------------------- |
| 版本   | 1.0                                                       |
| 适用对象 | 编写技术书籍的 AI Agent（人类编辑可作验收参考）                              |
| 载体   | 纸质书、电子书、连载成书                                              |
| 主题范围 | 技术类非虚构，不限语言与栈                                             |
| 文件性质 | 执行规范。合格与否由规则与脚本判定，不由自述判定                                  |
| 配套   | `tools/spec_lint.py`（校验与门禁）、`kit/`（9 份资产）、`README.md`（入口） |

---

## 目录

| 部分 | 标题        | 解决什么                  |
| -- | --------- | --------------------- |
| 0  | 作者身份与执行契约 | 你以什么身份写、以什么节奏写、哪些事不许做 |
| 1  | 立项        | 这本书该不该存在，承诺什么，不承诺什么   |
| 2  | 读者        | 写给谁，他进来时站在哪，出去时能做什么   |
| 3  | 全书结构      | 卷、章、节怎么切，怎么递进，怎么装配成书  |
| 4  | 写作单元      | 一节怎么从零写成一节，顺序与判据      |
| 5  | 主题三族      | 不同类型的技术内容，实战要求各不相同    |
| 6  | 语言与风格     | 句子、语气、幽默的分寸、图表、引用     |
| 7  | 校验        | 谁判、怎么判、判不过怎么办         |
| 8  | 书稿工程      | 分卷、习题、索引、前言、版次、多作者    |
| 9  | 交接        | 你交什么，人类验什么，冲突怎么裁      |
| A  | 规则总表      | 129 条规则一览，由脚本从正文派生    |
| B  | 模板索引      | `kit/` 九份资产与章节的对应关系   |
| C  | 门禁速查      | G0–G7 各一句话判据与常见失败     |
| D  | 故障处置      | 按症状查，不按原因查            |
| E  | 三族速查      | A/B/C 三族要求对照          |
| F  | 待校准项      | 所有未经真实书稿检验的数值         |
| G  | 术语表       | 本规范自用的概念定义            |
| H  | 文风样例      | 六组正反对照，风格的实际刻度        |

## 这份文件怎么读

**你不通读全文再动笔。** 上下文越长，靠后的约束越易被稀释。按当前动作取对应部分，其余留到那个阶段再取。

| 你正在做    | 只加载                                             | 先不要加载    |
| ------- | ----------------------------------------------- | -------- |
| 开工、恢复会话 | 第 0 部分 + `state.json`                           | 第 4–8 部分 |
| 选题      | 第 1 部分 + `kit/01_立项卡.json`                      | 第 6 部分   |
| 设计目录    | 第 2、3 部分 + `kit/02_outline.schema.json`         | 第 5 部分细节 |
| 写一节     | 第 4 部分 + 该节 spec + 前三节各 3 行摘要 + `glossary.json` | 全书正文     |
| 写实验与案例  | 第 5 部分 + 仓库当前分支                                 | 第 8 部分   |
| 语言收尾    | 第 6 部分 + 附录 H                                   | 第 1–3 部分 |
| 跑校验     | 第 7 部分 + 附录 A、C                                 | 第 5 部分   |
| 装配全书    | 第 8 部分 + 第 3.3 节                                | —        |
| 交付      | 第 9 部分                                          | —        |

规则按域编号，附录 A 可按域过滤。一次压进上下文两百条规则，等于没有规则。
