# 附录 C 门禁速查

| 门 | 一句话判据 | 不过会怎样 | 常见失败 |
|---|---|---|---|
| G0 | 有话可说、有据可查、范围有界 | 写完发现没内容或超范围 | `claim` 是主题名；`scope_out` 空 |
| G1 | 读者是可描述的对象，不是想象 | 定位错，全书白写 | 假设全是 `assumed` |
| G2 | 目录是数据结构，不是标题列表 | 章节漂移、重复、并列 | 节无 `produces`；有环；缺代价节 |
| G3 | 一节能完整跑通三层剥法 | 问题复制到全书 | 开头写太早、代价空 |
| G4 | 实验真跑过，不是描述过（**当前未实现；不要报假绿**） | 读者照着做失败 | 编造输出、无基线 |
| G5 | 全书作为一个整体自洽 | 引用失效、编号错乱 | 手写编号 |
| G6 | 未验证项已声明 | 读者把推断当事实 | 交接包缺 `05` |
| G7 | 十条红线全过 | 出版事故 | 用降级句式绕过事实检查 |
| G8 | 体量、阶段真实性、报告引文、台账、代码、结构（工具层质量扩展） | 合规空转、假冻结、代码不可编译 | 空模板报告；`done_units`≠frozen；C# 片段缺括号；坏 CSV 台账 |

**G4 现状**：`spec_lint.py` 对未实现门禁返回 P0，`run_gates` 会诚实显示 FAIL；在实现之前，`G0–G7 全绿`不成立。
