# 附录 C 门禁速查

| 门 | 一句话判据 | 不过会怎样 | 常见失败 |
|---|---|---|---|
| G0 | 有话可说、有据可查、范围有界 | 写完发现没内容或超范围 | `claim` 是主题名；`scope_out` 空 |
| G1 | 读者是可描述的对象，不是想象 | 定位错，全书白写 | 假设全是 `assumed` |
| G2 | 目录是数据结构，不是标题列表 | 章节漂移、重复、并列 | 节无 `produces`；有环；缺代价节 |
| G3 | 一节能完整跑通三层剥法 | 问题复制到全书 | 开头写太早、代价空 |
| G4 | 实验真跑过，不是描述过（**未实现；run_gates 默认 SKIP，`--require-g4` 强制执行**） | 读者照着做失败 | 编造输出、无基线 |
| G5 | 全书作为一个整体自洽 | 引用失效、编号错乱 | 手写编号 |
| G6 | 未验证项已声明 | 读者把推断当事实 | 交接包缺 `05` |
| G7 | 十条红线全过，**且依赖 G8**（门禁单调） | 出版事故 | 用降级句式绕过事实检查 |
| G8 | 体量、阶段真实性、报告引文、台账、代码、结构、**合同交付物与批量衰减**（工具层质量扩展） | 合规空转、假冻结、代码不可编译、量产尾部松劲 | 空模板报告；`done_units`≠frozen；C# 片段缺括号；坏 CSV 台账；末 ⅓ 章骤薄/挂牌增多；`repo:` 引用悬空（EVD-17）；P1 未签字却全书量产（WF-24）；固定块标题形态未裁决（QG-06） |

**G4 现状**：`spec_lint.py --gate G4` 仍诚实返回 P0（未实现的门禁不许假绿）；`run_gates` 默认把它标 `G4 SKIP` 并注明原因，避免「永远 HAS_FAIL」把真信号淹掉。需要强制时用 `run_gates --require-g4`。

**G7 单调性**：G8 有 P0 时，`run_gates` 会把 G7 由 PASS 改为 FAIL（「依赖 G8：发布门禁不成立」）。禁止出现「G7 PASS + G8 FAIL」这种自相矛盾的完成信号。
